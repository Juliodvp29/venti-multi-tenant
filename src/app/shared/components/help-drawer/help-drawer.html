¿Qué es un webhook?

Es un POST automático que Venti envía a una URL cada vez que ocurre un evento suscrito. Úsalo para automatizar tareas sin consultar Venti constantemente.

Conéctalo en 5 minutos

  1. 1. Abre Integraciones → Webhooks en el panel.
  2. 2. En Zapier, Make o n8n crea un disparador de tipo “Custom Webhook” y copia la URL.
  3. 3. Pega la URL en Venti y selecciona los eventos que necesitas.
  4. 4. Guarda el secreto mostrado una sola vez y configúralo en tu receptor.
  5. 5. Crea una orden de prueba y revisa la pestaña Entregas.

Verificar la firma

Calcula HMAC-SHA256 usando el cuerpo JSON exacto recibido y tu secreto. Compara el resultado hexadecimal con el encabezado X-Venti-Signature. No vuelvas a serializar el JSON antes de verificarlo. 

import crypto from 'node:crypto';

const expected = crypto
  .createHmac('sha256', process.env.VENTI_WEBHOOK_SECRET)
  .update(rawBody)
  .digest('hex');

if (expected !== request.headers['x-venti-signature']) {
  return response.status(401).send('Firma inválida');
}
